# Kiln Vertical Slice

A small 2D game that exercises the whole engine stack: art loaded from disk,
game rules written in KilnScript, save/load of the game state and an
on-screen HUD.

The project runs the same way in the standalone player and in the editor. It
is the reference sample for the completed 2D-first gate (G-1 … G-6).

## Playing It

Standalone player:

```sh
cargo run -p kiln-player -- --archive samples/vertical_slice
```

Editor: open `samples/vertical_slice/kiln.toml` (File → Open Project) and
press **Play** in the scene view.

## Controls

| Key | Action |
| --- | --- |
| Arrow keys or WASD | Move the hero |
| F5 | Save the game |
| F9 | Load the game |

## What Is In Here

| Path | What it is |
| --- | --- |
| `kiln.toml` | The manifest: window size, the scene and its entities |
| `art/hero.png` | The hero sprite, drawn from disk |
| `art/coin.png` | The coin sprite, drawn from disk |
| `art/ground.png` | The ground texture |
| `scripts/main.ks` | The game rules, written in KilnScript |

The art is generated by `art/generate_art.py`.

## Entity Reference

The scene in `kiln.toml` has six entities:

| Id | Role | Texture |
| --- | --- | --- |
| ground | ground | art/ground.png |
| player | player | art/hero.png |
| coin1 | coin | art/coin.png |
| coin2 | coin | art/coin.png |
| coin3 | coin | art/coin.png |
| coin4 | coin | art/coin.png |

The `Role` component lets the script find entities by purpose (`"player"`
and `"coin"`) instead of by index.

## How the Script Works

`scripts/main.ks` runs once per frame. It asks the engine for the input
axis and the frame length, moves the hero, collects a coin when it touches
one and keeps the score:

```
let speed = 120.0;
let dt = get_delta_time();
let dx = get_input_x() * speed * dt;
let dy = get_input_y() * speed * dt;
move_player(dx, dy);

if collect_coin() {
    add_score(10);
    set_status("PICKED UP A COIN");
}

if get_coin_count() == 0 {
    set_status("ALL COINS COLLECTED");
}
```

The engine provides the builtins the script uses (`move_player`,
`collect_coin`, `add_score`, `set_status`, `get_input_x`, `get_delta_time`
and more); the script only decides what happens.
