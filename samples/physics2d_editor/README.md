# Physics and cameras editor sample

Open `kiln.toml` through the native editor's File → Open Project, then Play.
Use left/right to move and up to jump. Try the slope, moving platform, amber
trigger, purple excluded collision layer, and bounded follow camera. Enable
Colliders to inspect the saved scene geometry.

The sample's scripts run in the `physics_workflow` regression suite. Full
authoring instructions and the pending graphical acceptance procedure are in
[`docs/PHYSICS_2D.md`](../../docs/PHYSICS_2D.md).
