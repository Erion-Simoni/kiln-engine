Arbitrary vertex/storage/uniform interfaces, live script parameter animation and every device's WGSL/backend compatibility are not certified. Old placeholder shader definitions need migration. Unused shader drafts can remain invalid; material definitions are validated even when not assigned. Native compilation on changed drafts is a measured-cost follow-up on reference hardware.
- Xvfb/SwiftShader/Mesa/ALSA null and simulated gamepad APIs do not certify physical Intel HD 520 performance or audible/physical controls. No laptop/device was connected. Clean Linux evidence is Ubuntu 24.04/X11 software graphics; Wayland, older glibc, other OS/browser engines and mobile need separate runs.
- Legacy JSON/metadata defaults missing capabilities false, deliberately preventing unsupported exports. Older readers may reject extended metadata. Physics opt-out runtimes remain usable for nonphysics projects.
- Linux bundles require compatible glibc (current binaries reference 2.39), system libraries and dynamic X11 support from shipped requirements. Test drivers add libraries; executed-path success is not universal/minimal system/driver/plugin closure. Libraries are not bundled.
- Internal packages with missing package-license declarations remain null; workspace policy/original notices are preserved without inventing grants. Revision/dirty/compiler fields are preparation observations. Release licensing/provenance remain open.
