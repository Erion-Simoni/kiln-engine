## Known issues and boundaries

- This is same-machine relocation/software evidence, not clean-machine dependency closure or physical hardware certification. No laptop/device was connected. Xvfb/SwiftShader/ALSA null and simulated gamepad API do not prove Intel HD 520 performance or audible/physical input behavior.
- The debug archive exceeds the <40 MB release installer target; debug player/WASM observations from earlier checkpoints likewise do not satisfy release budgets. No size/startup gate or budget exception is implied.
- Linux direct requirements include libasound.so.2; editor/player also need libudev.so.1, plus libgcc_s/libm/libc/ELF loader. GLIBC 2.39 is referenced. System libraries are not bundled; dynamically loaded display/GPU/audio plugins need separate clean-machine validation. Other OS bundles are unverified.
- Tool version/host/features and hashes cannot attest the source/compiler of arbitrary supplied binaries. Packaging source revision/dirty/compiler fields are observations of the preparing checkout; exact/reproducible build provenance and release license review are still required.
- Prepared browser export rejects physics/joints and sprite material overrides. Other browser engines/mobile/real controllers remain unverified. HTTP deployment passes; file:// is unsupported and managed Chromium previously blocked that navigation through administrator policy.
- Remote GitHub Actions/installer signing/release uploads have not been observed. CI configuration and local tests are not a claim of remote success.
