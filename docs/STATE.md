## Known issues and boundaries

- Build records are unsigned and can be changed together with unsigned manifests; obtain artifacts through trusted channels. Two builds shared the host, tool versions, SDK and dependency source cache while using fresh source/target directories. Those external inputs are not fully captured/hermetic or independently attested. Archives differ because per-execution records/log/path observations differ; only the six specified payloads are claimed byte-identical.
- Material support remains the documented fixed-vertex/custom-fragment contract with typed static constants/named textures. Arbitrary vertex/storage/uniform interfaces/live script parameter animation are outside it; old placeholder definitions need migration. See SPRITE_MATERIALS_2D.md and task8-materials evidence.
- Xvfb/SwiftShader/Mesa/ALSA null/simulated gamepads cannot certify physical Intel HD 520 performance or audible/physical controls. Existing clean runtime evidence is Ubuntu 24.04/X11; Wayland, older glibc, other OS/browser engines and mobile need separate runs. Release ELF observations require GLIBC 2.39 and shipped dynamic-library requirements; system libraries are not bundled.
- Legacy capabilities default false and block unsupported exports. Upgrade tools/player/prepared browser files together. Internal license omissions remain null; original notices/workspace policy are preserved without inventing grants.
- No signed installer, release upload, remote CI or physical/reference-hardware performance result is implied. Package size never blocks completion; technical bounded-file/input limits remain.
