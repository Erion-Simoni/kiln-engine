# Kiln Engine

Kiln is a native editor and runtime for authoring and exporting games. The current
engine supports small 2D games; production acceptance and broader 2D tools remain
in progress. The 3D preview is scaffolding for future integrated 3D work.

Start with [Getting Started](GETTING_STARTED.md), then follow the
[Tutorial](TUTORIAL.md). See [Engine Overview](ENGINE_OVERVIEW.md) for the engine
structure and [API Reference](API_REFERENCE.md) for supported APIs.

The [Engine Completion Plan](ENGINE_COMPLETION_PLAN.md) is the authoritative
roadmap for remaining 2D, 3D, production and platform work. Historical plans and
checked milestones retain their evidence; current acceptance follows that plan.

For packaging and target limitations, read [Portable Editor](PORTABLE_EDITOR.md),
[Windows Portable](WINDOWS_PORTABLE.md) and [Physical Device Testing](PHYSICAL_DEVICE_TEST.md).
