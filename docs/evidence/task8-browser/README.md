`editor-result.json` records saved edits, runtime sizes and preservation assertions.
`browser-result.json` records nested deployment, controller API navigation, one
activation per touch, running/looping Web Audio and overlapping effects, settings,
save/reload/resume, quota/corrupt-save preservation, loading and retry assertions.
Full logs/screenshots are generated by `tests/native/browser_export_smoke.py` and
`tests/native/relocated_browser_export.py` and uploaded by CI.

This is Xvfb/software graphics, Chromium/SwiftShader and simulated controller
input, not physical-device or other-browser/OS certification. Managed Chrome
blocks file:// navigation with ERR_BLOCKED_BY_ADMINISTRATOR; its HTTP-guidance
branch is unverified and file launching is unsupported. Browser physics/joints
and material overrides are refused until their host integration exists. Native
clean-machine/release/ABI acceptance and portable editor distribution remain open.
